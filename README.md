# Machine Learning-Based Dengue Severity Risk Classification Using Patient-Level Surveillance Data
This project develops a machine learning-based analytical framework for dengue severity risk classification using patient-level clinical, demographic and geographical surveillance data.

The study utilizes dengue case records obtained from Brazil's national notifiable disease surveillance system, SINAN (Sistema de Informação de Agravos de Notificação).

The primary objective is to identify patient characteristics and clinical indicators associated with different dengue severity levels and develop predictive models to classify patients into three risk categories:

Low Risk: Regular dengue

Medium Risk: Dengue with warning signs

High Risk: Severe dengue

The project demonstrates an end-to-end data science workflow, covering business understanding, data exploration, data preparation, supervised machine learning, model evaluation and deployment planning.
